# Sistema de Gestão CCBJ

Sistema interno de gestão modular para operações culturais, administrativas e estratégicas do Centro Cultural Bom Jardim.

---

## 📌 Estrutura do Projeto

- html/ → Interface e módulos visuais
- logic/ → Núcleo de lógica do sistema
- services/ → Integrações e comunicação com backend
- docs/ → Documentação técnica estruturada

---

## 🧠 Documentação Técnica

A documentação completa do sistema está organizada em:

- docs/mapa_sistema.md → Visão geral e arquitetura
- docs/index_tecnico.md → Índice navegável
- docs/analise_arquivos/ → Análise detalhada por arquivo
- docs/padroes/ → Padrões técnicos e estruturais
- docs/logs/ → Histórico de evolução

---

## 🚀 Objetivo

Permitir:

- Mapeamento completo do sistema
- Identificação de falhas estruturais
- Redução de redundâncias
- Evolução modular e escalável

---

## ⚠️ Observação

Este sistema está em processo ativo de análise e refatoração.
