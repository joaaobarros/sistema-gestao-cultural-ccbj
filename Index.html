Manual de Utilização

Sistema de Gestão de Espaços — CCBJ

Bem-vindo ao Sistema de Gestão de Espaços do CCBJ!

Este sistema permite reservar espaços, gerenciar itens e acompanhar a agenda institucional.

Use as abas acima para navegar pelo manual de cada seção do sistema.

Agenda Geral

Exibe todas as reservas cadastradas no sistema, das mais antigas às mais recentes.

Novo Agendamento

Permite criar reservas de espaços com ou sem itens do almoxarifado.

Reservas em lote criam entradas individuais para cada data selecionada.

Agenda RECE

Registro de eventos culturais para divulgação externa.

Configurações

Gerenciamento de espaços, itens, setores e usuários.

Auditoria

Histórico completo de todas as ações realizadas no sistema.

O rollback é irreversível.

Dashboard

Visão analítica do uso dos espaços e recursos.

Inteligência (IA)

Assistente de gestão baseado em IA integrado aos dados reais do sistema.

A IA opera exclusivamente sobre os dados internos do CCBJ. Nenhuma informação é enviada a terceiros além da API de IA configurada.

Aprovações

Fluxo de solicitações que requerem validação de um administrador antes de serem executadas.

Configure o e-mail do responsável em Configurações > Espaços para receber notificações automáticas.
